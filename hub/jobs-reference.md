# Jobs Reference

The [Jobs](/docs/hub/jobs) guide documents the public CLI, runtime states,
pricing rules, and endpoint groups. The live
[OpenAPI Explorer](/spaces/mega/openapi#tag/Jobs) is authoritative for request
schemas, response fields, and currently supported hardware.

Write clients that handle `401`, `402`, `403`, `422`, `429`, and `5xx` errors.
Treat returned IDs, cursors, and hardware identifiers as opaque values.
