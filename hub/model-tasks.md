# Model Tasks

Use concise, stable task tags to help readers find a model. A task tag is a
discovery signal, not proof that a release is compatible with a particular
runtime or inference endpoint.

Describe inputs, outputs, constraints, and intended use in the model card.
Add evaluation evidence for the task and metric you claim. For a model that is
routed by MEGA Inference Providers, consult the
[Model Catalog](/docs/inference-providers/model-catalog) for live availability.
