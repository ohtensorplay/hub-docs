# Datasets Overview

Dataset repositories provide versioned files, a dataset card, discovery
metadata, and controlled access. Use a dataset repository for material that
needs a reproducible revision and a documented schema.

Start with [Dataset Repositories](/docs/hub/datasets) for the core workflow.
Use the focused pages in this section for cards, upload, download, streaming,
and file organization.

Before publishing, verify distribution rights, remove unintended personal data,
declare provenance and license terms, and tag the exact revision used by an
experiment.
