# Model Hardware

Model repositories can document the hardware and software assumptions used for
training, evaluation, conversion, and inference. Put this information in the
model card alongside the exact revision and evaluation method.

Hardware claims are contextual, not a compatibility guarantee. State batch
size, precision, runtime version, and any relevant memory constraint when they
materially affect a result. For hosted execution options, see
[Jobs](/docs/hub/jobs), [Spaces](/docs/hub/spaces), and
[Inference Providers](/docs/inference-providers/index).
