# Publisher Analytics

Publisher Analytics is a Team and Enterprise organization feature for reviewing
how the organization's models, datasets, and Spaces are being published and
used. It brings high-level repository reach and release activity into one
organization settings view.

## Open Publisher Analytics

An organization administrator can open **Organization Settings → Publisher
Analytics**. The page shows the organization's repository count, downloads,
Jobs activity, and the repositories with the most current reach.

Analytics are aggregated by organization ownership. The dashboard does not
expose raw visitor identities.

## Review repository reach

Use the repository list to compare models, datasets, and Spaces by download
count, likes, visibility, and recent update time. This helps identify a release
that needs a clearer card, a new revision, a discussion response, or a follow-up
Job.

Start from the related product documentation when taking action:

- [Repository Cards](/docs/hub/repository-cards) for release context and use
  guidance.
- [Model Repositories](/docs/hub/models) and
  [Dataset Repositories](/docs/hub/datasets) for a new revision.
- [Spaces](/docs/hub/spaces) for an interactive application.
- [Jobs](/docs/hub/jobs) for repeatable release or evaluation work.

## Use the signals responsibly

Downloads and likes are useful publishing signals, not a quality or safety
guarantee. Review the repository card, task fit, license, data limitations,
and evaluation evidence before using a popular release.

Publisher Analytics does not change repository visibility or membership. Use
[Organizations](/docs/hub/organizations),
[Gated Repositories](/docs/hub/gated-repositories), and
[Resource Groups](/docs/hub/resource-groups) to manage access.

## Availability

The current plan and organization settings page are authoritative for feature
availability. Team and Enterprise include Publisher Analytics; other controls
may require a different plan or administrator permission.
