# Jobs Overview

MEGA Jobs runs a public container image and command for a bounded duration.
Use Jobs for batch tasks, scripts, scheduled work, and reproducible command
execution that does not need a long-lived public application.

Use [Spaces](/docs/hub/spaces) for an interactive web application. Use
[Sandboxes](/docs/hub/sandboxes) when a supported interactive execution session
fits the workflow. The full Job contract is documented in [Jobs](/docs/hub/jobs).
