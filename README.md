# MEGA documentation

This repository regroups the documentation hosted on the TensorPlay MEGA
website. Its multi-application layout follows the Hugging Face `hub-docs`
repository: each documentation application owns a directory below `docs/`.

| Application | Source | Published documentation |
| --- | --- | --- |
| MEGA Hub | [`docs/hub`](docs/hub) | [Hub documentation](https://mega.tensorplay.cn/docs/hub/index) |
| Megatensors | [`docs/megatensors`](docs/megatensors) | [Megatensors documentation](https://mega.tensorplay.cn/docs/megatensors/index) |
