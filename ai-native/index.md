# AI Native

Use MEGA from Codex with the MEGA Codex plugin or with standalone MEGA Agent
Skills. The plugin connects Codex to MEGA workflows and includes focused Skills
for common Hub tasks. Standalone Skills can also be installed for Codex and
other supported coding agents.

## Choose an installation path

| You want to… | Use… |
| --- | --- |
| Connect Codex to MEGA and install the bundled workflow guidance | The [MEGA Codex plugin](/docs/ai-native/install) |
| Add only selected, portable MEGA workflow Skills | [MEGA Agent Skills](/docs/ai-native/skills) |

The plugin provides the most direct Codex setup. Skills complement the plugin:
they help Codex choose the appropriate MEGA workflow for repositories,
datasets, Spaces, Jobs, Sandboxes, inference, and community work.

## What you can do

With the integration, Codex can identify the connected account; discover and
inspect repositories, papers, and profiles; make appropriately scoped text-file
or lifecycle changes; open and configure Spaces; operate Jobs, schedules, and
Sandboxes; and work with collections, posts, and repository discussions. It
guides local files, large transfers, Git, long-running Jobs, and streaming logs
to the CLI workflow.

You approve access through the normal MEGA authorization flow. Only grant the
permissions needed for the task, and review the target before authorizing a
write or deletion.

Start with [Install the MEGA Codex Plugin](/docs/ai-native/install), then see
[MCP Workflows in Codex](/docs/ai-native/mcp-workflows) and the
[MEGA Skills Catalog](/docs/ai-native/skills-catalog).
