# MEGA Skills Catalog

The MEGA Skills catalog contains one general router and focused workflow
guidance for common Hub tasks.

| Skill | Use it for |
| --- | --- |
| `mega` | Choosing between the connected MEGA workflow and the CLI for any MEGA task. |
| `mega-cli` | Local files, Git, bulk transfers, streaming logs, scripts, and automation. |
| `mega-repositories` | Model, dataset, and Space repositories; files, revisions, and publishing. |
| `mega-datasets` | Dataset discovery, transfer, versioning, and preparation. |
| `mega-spaces` | Space discovery, dynamic tools, runtime, configuration, lifecycle, and deployment workflows. |
| `mega-jobs` | Remote Jobs, schedules, Sandboxes, logs, costs, secrets, and output handling. |
| `mega-inference` | Model discovery, inference paths, limits, credentials, and output validation. |
| `mega-community` | Papers, collections, posts, comments, discussions, and pull requests. |

## Start with `mega`

Install `mega` when you are unsure which focused Skill you need. It routes
common discovery and small online tasks to the connected workflow and directs
local, bulk, streaming, secret-bearing, and long-running work to the CLI.

## Use a focused Skill

Install a focused Skill when a project primarily works in one area. For
example, use `mega-datasets` for a data-preparation repository or `mega-jobs`
for recurring remote workloads. You can install more than one Skill when a
project crosses those areas.

See [MEGA Agent Skills](/docs/ai-native/skills) for installation commands.
